# Запуск на Windows (твой компьютер)

## Первый раз

1. Установи **Python 3.10+** с [python.org](https://www.python.org/downloads/), галочка **Add Python to PATH**.
2. Клонируй репозиторий с GitHub (или распакуй архив) в папку, например `Project 1`.
3. Запусти **`setup_windows.bat`** в корне проекта (двойной клик).  
   - Создастся папка **`.venv`** с зависимостями.  
   - Если нет **`telegram_bot/config.py`**, скопируется из **`config.example.py`**.
4. Открой **`telegram_bot/config.py`** и укажи как минимум:
   - **`BOT_TOKEN`** — от @BotFather  
   - **`OWNER_CHAT_ID`** — свой числовой id (после первого запуска можно написать боту `/myid`, если команда есть)

## Каждый день

- Запуск: **`START_BOT.bat`** (корень проекта).  
- Окно **не закрывай** — пока оно открыто, работает супервизор `run_bot.py` (автоперезапуск при сбое и при сохранении кода).  
- Остановка: **`STOP_BOT.bat`** или закрыть окно.

## Стабильность

| Что даёт стабильность | Как у тебя сделано |
|------------------------|-------------------|
| Автоперезапуск после падения | `telegram_bot/run_bot.py` |
| Перезапуск при правках `bot.py`, `config.py`, … | тот же `run_bot.py` |
| Изоляция зависимостей | виртуальное окружение `.venv` |

Чтобы бот поднимался **сам после перезагрузки ПК**:

1. **Планировщик заданий** Windows → «Создать задачу».  
2. Триггер: «При входе в систему» (или «При запуске компьютера»).  
3. Действие: запуск программы — полный путь к **`START_BOT.bat`**, рабочая папка — корень проекта.  
4. Параметр «Выполнять с наивысшими правами» обычно не нужен.

## Админ-панель локально (по желанию)

В корне после `setup_windows.bat`:

```bat
.venv\Scripts\activate
cd dashboard
python app.py
```

Открой в браузере `http://127.0.0.1:8080`. На Windows статус «бот работает» через systemd не покажется — это нормально; бот смотри по окну `START_BOT.bat`.

## GitHub

Репозиторий хранит **код**. Секреты в **`config.py`** в Git не попадают (см. `.gitignore`). На новом ПК: `git clone` → `setup_windows.bat` → снова создать или скопировать **`config.py`** с токенами.
